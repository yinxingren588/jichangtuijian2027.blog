# 2027科学上网新手教程：Clash Verge Rev与Sing-box一键配置指南

随着 Clash 早期核心内核停止维护，进入 2026-2027 年后，**Clash Verge Rev**（基于全新 Clash.Meta / Mihomo 内核）与 **Sing-box** 已经成为电脑端（Windows / macOS）无可争议的新一代霸主；而在手机端，iOS 的 **Shadowrocket（小火箭）** 和安卓端的 **Clash Meta for Android** 依然是最稳健的选择。

如果你刚在“2027机场推荐”榜单中选购了心仪的节点服务，不知道如何将订阅导入到客户端中，本文将以保姆级的图文逻辑，带你在 3 分钟内完成全套配置。

## 阶段一：各平台客户端选择与安装

请根据你的设备操作系统下载对应客户端：

### 1. Windows 用户
- **推荐客户端**：**Clash Verge Rev**
- **优势**：现代化 UI 界面、内置中文、完美支持系统级代理与 Tun 虚拟网卡模式、协议支持全面（包含 Hysteria 2、VLESS-Reality 等）。

### 2. macOS 苹果电脑用户
- **推荐客户端**：**Clash Verge Rev for Mac** 或 **Sing-box**
- **注意**：M 系列芯片（M1/M2/M3/M4）用户请下载对应的 `arm64` 版本；Intel 老款芯片用户请下载 `x64` 版本。

### 3. iOS 苹果手机 / iPad
- **推荐客户端**：**Shadowrocket（俗称“小火箭”）**
- **获取方法**：由于国内 App Store 下架，需要注册或借用一个“外区（如美区、日区、港区）” Apple ID，在 App Store 搜索购买下载（费用约 2.99 美元）。

### 4. Android 安卓手机
- **推荐客户端**：**Clash Meta for Android（CMFA）** 或 **Sing-box Android**
- **优势**：开源免费，直接下载 `.apk` 安装包即可安装，支持分应用代理设置。

## 阶段二：如何获取机场订阅链接？

1. 登录你在本站推荐中注册的机场用户中心（例如“隐形人”或“微风网络”）；
2. 进入【仪表盘】或【我的订阅】页面；
3. 找到【一键订阅】按钮；
4. 点击【复制订阅地址】（如果是手机操作，也可以直接点击【一键导入到 Shadowrocket / Clash】）。

> ⚠️ **新手避坑提醒**：订阅链接相当于你的私人通行密码，切勿将订阅 URL 分享给任何人，否则别人将可以直接使用你的流量配额！

## 阶段三：Clash Verge Rev 导入配置（详细步骤）

1. 打开 **Clash Verge Rev** 客户端；
2. 点击左侧菜单栏的 **【配置】（Profiles）**；
3. 在顶部的输入框中粘贴刚刚从机场复制的订阅 URL 链接；
4. 点击右侧的 **【导入】（Import）** 按钮，客户端将自动下载节点配置文件；
5. 右键单击新下载的配置，选择 **【使用】（Use）**；
6. 点击左侧 **【代理】（Proxies）** 选项卡，在节点列表中选择一个低延迟节点（如“香港 IPLC 01”或“自动选择”）；
7. 点击左侧 **【设置】（Settings）**，将 **【系统代理】（System Proxy）** 的开关拨到打开状态。
8. 此时打开浏览器访问 `google.com` 或 `youtube.com`，即可享受高速畅联！

## 阶段四：常见问题与排查思路

### Q1：开启代理后依然无法打开外网网页？
- **检查步骤**：
  1. 查看电脑系统时间是否准确，时间如果慢了或快了超过 60 秒，TLS 加密证书会握手失败；
  2. 检查客户端左侧【代理】中是否实际选中了节点，有些节点可能处于维护状态，可尝试点击右下角 Wi-Fi 图标进行测速并切换其他节点；
  3. 确认杀毒软件或防火墙没有拦截客户端的本地回环端口（通常为 7890）。

### Q2：访问国内网站（百度、淘宝）速度变慢？
- **原因**：你的分流模式被错误设为了“全局（Global）”。
- **解决方法**：在 Clash 客户端的代理模式中，务必选择 **【规则（Rule）】** 模式。在规则模式下，国内网站自动直连，国外被屏蔽网站自动走专线加速，两者互不干扰。
